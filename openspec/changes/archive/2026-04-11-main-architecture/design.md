## Context

Kuake CLI 是一个夸克网盘非官方第三方 CLI/SDK 工具，使用 Go 语言开发。项目目前包含：

- **sdk/**: 核心 SDK 模块，提供 API 客户端和业务逻辑封装
- **cmd/**: 命令行入口，处理 CLI 参数和用户交互
- **config.json**: 运行时配置文件

当前问题：
- 缺乏统一的架构设计文档
- 模块划分和组件关系没有明确说明
- 新开发者难以快速理解系统设计

## Goals / Non-Goals

**Goals:**
- 创建主规格文档 `specs/architecture/spec.md` 作为项目的长期架构参考
- 明确分层架构、模块划分、核心组件交互关系
- 记录关键设计决策和技术选型理由
- 为新功能开发提供架构指导

**Non-Goals:**
- 不涉及具体 API 接口的详细定义（这些在现有代码和 OpenSpec 变更中维护）
- 不涉及单元测试策略（已有测试文件）
- 不涉及部署和运维细节

### 模块划分

| 模块 | 路径 | 职责 |
|------|------|------|
| 核心客户端 | sdk/quark_client.go | API 客户端封装、Token 管理、认证检查 |
| 文件操作 | sdk/file.go | 文件上传下载、目录操作、并行上传 |
| 用户操作 | sdk/user.go | 用户信息、容量查询 |
| 分享操作 | sdk/share.go | 分享创建、取消、转存 |
| 配置管理 | sdk/config.go | 配置文件加载和保存 |
| 常量定义 | sdk/constants.go | API 路径、域名、配置路径常量 |

### 技术选型

| 技术 | 选择理由 |
|------|----------|
| Go 1.18+ | 跨平台编译、性能好、类型安全 |
| 原生 HTTP 客户端 | 稳定、无外部依赖、支持超时和重试 |
| JSON 序列化 | 标准库支持、跨平台兼容性好 |
| MIT/gopls | LSP 服务器，提供代码智能提示 |

### 错误处理策略

- **可重试错误**: EOF、连接重置、超时等网络瞬时故障 → 指数退避重试
- **不可重试错误**: 认证失败、参数错误 → 立即返回
- **分片级错误**: 并行上传中单个分片失败 → 不影响其他分片，返回第一个错误

### 并发模型

- **上传**: 使用 channel 实现生产者-消费者模式
  - producer 协程：读取文件分片
  - worker 协程：并行上传分片
  - result collector：收集结果并处理错误

## Risks / Trade-offs

| 风险 | 缓解措施 |
|------|----------|
| API 变更导致功能失效 | 保持 API 路径常量集中管理，便于快速定位和更新 |
| Token 过期导致服务中断 | 定期认证检查缓存（默认 5 分钟），失败时自动切换 Token |
| 并行上传导致资源占用高 | 可配置的并行度参数，默认值保守 |
| 大文件上传中断 | 断点续传支持，已上传分片状态持久化到临时文件 |
